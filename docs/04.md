## 不建议我们现在立刻把所有页面搬到 `/en`

因为你现在的英文 URL 已经是：

```text
/profit-calculator
/fee-calculator
/roas-calculator
```

如果现在突然改成：

```text
/en/profit-calculator
```

会导致以后 SEO URL 发生变化。

### 所以第一版应该：

```text
/                         English
/tools                    English
/profit-calculator        English
/fee-calculator           English
/roas-calculator          English

/zh                       Chinese
/zh/tools                 Chinese
/zh/profit-calculator     Chinese
/zh/fee-calculator        Chinese
/zh/roas-calculator        Chinese
```

这样**保留现有英文 URL**，中文新增 `/zh`。

这是我更推荐的。

# 更重要的是：中文不是简单翻译

我们要把**计算逻辑和语言完全分离**：

```text
components/
    Calculator.tsx

lib/
    calculator.ts

i18n/
    en.ts
    zh.ts
```

例如：

```ts
export const zh = {
  nav: {
    tools: "工具",

    about: "关于我们",
  },
```

# SEO 也必须多语言

这个非常重要。

英文：

```text
/profit-calculator

Title:
TikTok Shop Profit Calculator | SellerCalc AI

Description:
Calculate TikTok Shop profit...
```

中文：

```text
/zh/profit-calculator

Title:
TikTok Shop利润计算器 | SellerCalc AI

Description:
计算TikTok Shop商品利润、平台费用、达人佣金和广告成本。
```

并且加入：

```html
hreflang
```

告诉 Google：

```text
/profit-calculator
        ↕
/zh/profit-calculator
```

两个页面是**不同语言版本，而不是重复内容**。

验证产品。

> Spanish + German + French
